# Интеграционный тест распознавания

Тест загружает PDF, проверяет HTTP 200 и до 60 секунд ждёт входящий результат в PostgreSQL. Затем он сравнивает поля из `payload.request.content.prd` с эталоном.

1. Перед `uv sync` добавь в `pyproject.toml` настройки индекса. Подставь адрес корпоративного PyPI вместо `Сбер osc`.

   ```toml
   [[tool.uv.index]]
   name = "corporate"
   url = "Сбер osc"
   default = true
   ```

   Если индекс уже настроен в локальном `uv.toml`, используй этот файл. Затем выполни `uv sync` в терминале из папки проекта.

2. Скопируй `.env.example` в `.env`. Укажи адрес стенда, имя PDF и PostgreSQL DSN с логином без пароля. Если подключение к БД требует специальных параметров SSL, перенеси их из рабочего подключения.
3. Добавь в `~/.pgpass` одну строку в формате `хост:порт:база:логин:пароль`. Первые четыре поля должны совпадать с `DB_DSN`. В пароле перед `:` и `\` поставь обратный слэш. Остальные символы впиши как есть. На Linux и macOS выполни `chmod 600 ~/.pgpass`.
4. Положи рядом с тестом PDF, `tls.pem`, `tls.key` и рабочий `request.json` с идентификатором тестового клиента и типом документа. `request.example.json` показывает формат для отчёта арбитражного управляющего.
5. Скопируй `expected.example.json` в `expected.json`. Замени пример полями и значениями для своего документа. Ключи задаются через точку относительно `prd`.
6. Запусти тест из папки проекта. Драйвер PostgreSQL прочитает пароль из `~/.pgpass` автоматически.

```bash
uv run --env-file .env python -m pytest -q test_recognition.py
```

### Интервал опроса и таймаут

Оба значения можно поменять вручную в начале `test_recognition.py`. Они указаны в секундах.

- `POLL_INTERVAL = 1` — пауза перед следующим запросом к PostgreSQL, если запись ещё не нашлась.
- `RESULT_TIMEOUT = 60` — максимальное время, в течение которого тест ищет результат после HTTP 200.

Первый запрос к БД выполняется сразу после HTTP 200. Например, чтобы ждать до двух минут с паузой в две секунды, задай `RESULT_TIMEOUT = 120` и `POLL_INTERVAL = 2`.

Запускай тест последовательно, когда у агента нет других загрузок. API не возвращает идентификатор загрузки, поэтому чужой или запоздавший результат с подходящим временем может попасть в выборку. Загруженный файл и запись в БД сохраняются.
