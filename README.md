# Интеграционный тест распознавания

Тест загружает PDF и JSON запроса для выбранного сценария, проверяет HTTP 200 и до 60 секунд ждёт запись о распознавании в БД. Затем он сверяет выбранные поля результата с эталоном.

1. Перед `uv sync` добавь в `pyproject.toml` настройки индекса. Подставь адрес корпоративного PyPI вместо `Сбер osc`.

   ```toml
   [[tool.uv.index]]
   name = "corporate"
   url = "Сбер osc"
   default = true
   ```

   Если индекс уже настроен в локальном `uv.toml`, используй этот файл. Затем выполни `uv sync` в терминале из папки проекта.

2. Скопируй `.env.example` в `.env` и укажи адрес стенда.
3. Скопируй `db.example.yaml` в `db.local.yaml`. В поле `dsn` укажи PostgreSQL DSN с логином без пароля. Если для подключения нужны параметры SSL, добавь их в DSN. На строке под `password: |-` оставь два пробела отступа и вставь пароль как есть, без кавычек вокруг него и URL-кодировки. На Linux и macOS выполни `chmod 600 db.local.yaml`.
4. Положи `tls.pem`, `tls.key` и `request.json` в корень проекта. Формат запроса показан в `request.example.json`. Укажи идентификатор тестового клиента и тип выбранного документа.
5. Положи PDF в `Docs/input`, а эталонный JSON в `Docs/expected`. Дай им одинаковое имя без учёта расширения, например `2ndfl.pdf` и `2ndfl.json`. В эталоне задай пути полей относительно `payload.request.content.prd` и их ожидаемые значения. Формат показан в `Docs/expected/expected.example.json`.
6. В начале `test_recognition.py` задай имя сценария, например `CASE = "2ndfl"`, и запусти тест из папки проекта.

```bash
uv run --env-file .env python -m pytest -q -s
```

### Интервал опроса и таймаут

Оба значения можно поменять вручную в начале `test_recognition.py`. Они указаны в секундах.

- `POLL_INTERVAL = 10` — пауза перед следующим запросом к PostgreSQL, если запись ещё не нашлась.
- `RESULT_TIMEOUT = 60` — максимальное время, в течение которого тест ищет результат после HTTP 200.

Первый запрос к БД выполняется сразу после HTTP 200. Например, чтобы ждать до двух минут с паузой в две секунды, задай `RESULT_TIMEOUT = 120` и `POLL_INTERVAL = 2`.

Запускай тест последовательно, когда у агента нет других загрузок. API не возвращает идентификатор загрузки, поэтому чужой или запоздавший результат с подходящим временем может попасть в выборку. Загруженный файл и запись в БД сохраняются.
